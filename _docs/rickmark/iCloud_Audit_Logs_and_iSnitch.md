# iCloud Audit Logs and iSnitch

# Introduction

Apple lacks in proper online service audit logs.  While they use e-mail to communicate some of the security events for an Apple account, they do not surface this data in a security audit log.  Moreover not all of the relevant events are delivered by this method.  This paper analyzes this gap and proposes a potential solution.
