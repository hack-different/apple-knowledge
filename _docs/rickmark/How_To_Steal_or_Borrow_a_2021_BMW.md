# Option A: Clone a Fob
## Key Fobs Have Versions

Don't be fooled by keys that look the same.  A BMW key fob is of a particular hardware revision, majors are in letter form and minors are in numerical.  The one exception to the A, B, C procession is the N series keys known as the “display key”.  Naturally later letters are later versions of the key.  You can find on eBay “B48” or “B58” keys.  These indicate B generation and a minor revision.  Now do not buy second hand keys.  The reason for this is that B generation keys are known to be trivially clonable by duplicating the ISN of a key.  This is done by using the pads for a “pogo pin” board to directly communicate with the onboard EEPROM.  When you buy a new BMW the fobs should match, same revision and be of the generation expected for such a vehicle.  Mine no longer match… I have one C19 and one C25, and there are D revision keys.  I have complained to my dealership multiple times about intermittent locking issues, and if the Fob doesn't “hard fault” the warranty won't replace it, even if it's obvious that it isn't the key intended for the car.
